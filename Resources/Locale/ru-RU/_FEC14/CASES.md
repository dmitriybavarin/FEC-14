# Падежи в русской локализации FEC-14

В строках локализации имя сущности или игрока можно поставить в нужный падеж функцией `CASE`:

```ftl
cm-tackle-success-self = Вы сбиваете { CASE($target, "acc") } с ног!
```

| Код | Падеж | Вопрос |
|---|---|---|
| `gen` | родительный | кого? чего? |
| `dat` | дательный | кому? чему? |
| `acc` | винительный | кого? что? |
| `ins` | творительный | кем? чем? |
| `prep` | предложный | о ком? о чём? |

## Как работает

1. **Предметы и сущности.** Формы берутся из атрибутов прототипа в `ent-*`. Если атрибута нет, остаётся именительный падеж.

   ```ftl
   ent-FECMeteoStation = метеорологическая станция
       .gen = метеорологической станции
       .dat = метеорологической станции
       .acc = метеорологическую станцию
       .ins = метеорологической станцией
       .prep = метеорологической станции
   ```

   Если предмет переименован (название не совпадает с прототипом), берётся новое название без склонения.

2. **Имена персонажей** («Иван Петров», «Рядовой Сергей Волков», «Анна Смирнова») склоняются автоматически с учётом пола. Сокращения со точкой («Ряд.»), латиница и несклоняемые фамилии («Шевченко») не меняются.

3. **Скрытая личность.** Если персонаж в маске, используется имя, которое видит игрок, настоящее имя не раскрывается.

## Правила для переводчиков

- Не выбрасывайте `$target`, `$user`, `$targetName` из перевода. Используйте `CASE`, чтобы игрок видел, с кем произошло действие.
- Добавляйте атрибуты падежей для часто упоминаемых предметов (оружие, инструменты, машины), чтобы фразы с ними звучали правильно.
