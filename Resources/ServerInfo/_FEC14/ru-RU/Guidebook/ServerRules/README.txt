В этих файлах правила серверов Wizard's Den. Поскольку они ссылаются на Wizard's Den, другим серверам не стоит
использовать их без изменений, достаточных, чтобы игроки не думали по ошибке, что играют на Wizard's Den.

Имена файлов с правилами сами по себе правилами не являются. Правила только то, что написано внутри файлов.
